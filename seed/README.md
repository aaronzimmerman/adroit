# The adroit engineering seed

Default engineering decision records a new adroit-backed project starts from, distilled from a mature production ledger.
At kickoff a project COPIES the nodes it wants into its own `ledger/engineering/` and owns them from then on (ADROIT.md, The engineering seed): contextualize a copy or reverse it, with the reason recorded in the node itself.
A copy never references back to this seed; `context.src` names its origin and that is the whole relationship.
